# The Mossy Rock Simulator-Sim

A simple generative art page where you can plant moss on a rock-colored background. 

## Features
- **Planting**: Click anywhere on the canvas to create a patch of moss.
- **Weather Effects**: Toggle between 'Sunny' and 'Rainy' modes. 
- **Dynamic Colors**: The moss changes color from a dry, olive-green to a lush, vibrant green when it rains, and it grows slightly larger to soak up the water.
