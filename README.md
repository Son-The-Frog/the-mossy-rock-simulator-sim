# The Mossy Rock Simulator-Sim

A simple generative art page where you can plant moss on a rock-colored background.

## Features
- **Planting**: Click anywhere on the canvas to create a patch of moss.
- **Weather Effects**: Toggle between Sunny and Rainy weather to see the moss colors change.
- **Soundscapes**: Synthetic rain and 'tap-tap-tap' sounds created using the Web Audio API.
- **Sound Toggle**: A button to turn the audio on or off.
